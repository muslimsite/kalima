# Данные «Калимы»

## Файлы

- `words.json` — словарь: `meta`, наборы `sets` в порядке изучения, карточки `words` (417 слов), `prefixes` (приставки و ف ب ل ك ال س لَ أَ) и `suffixes` (слитные местоимения ـهُ ـهَا ـهُمْ ـكَ ـكُمْ ـنَا ـي).
- `coverage.json` — какую долю слов текста Корана покрывают выученные слова, если учить их по порядку.
- `suras/<n>.json` — суры 1 и 78–114 для режима «мусхаф»: аяты по словам, у каждого слова `id` карточки или `null`. `suras/index.json` — список сур.

## Источники

- Арабский текст: Tanzil, «Simple» с полной огласовкой (`quran-simple`), через api.alquran.cloud.
- Перевод: Э. Р. Кулиев (`ru.kuliev`), через api.alquran.cloud.
- Леммы, корни и частотность: Quranic Arabic Corpus, morphology 0.4 (Kais Dukes).

## Как собрано

1. По морфологии QAC посчитаны все основы (STEM) по леммам: 77 429 слов текста. `freq` — это число употреблений леммы. У личных местоимений (هُوَ، هُمْ…) учтены только отдельно стоящие формы.
2. Порядок изучения:
   - Аль-Фатиха;
   - суры 114→103 полностью;
   - суры 102→78, из каждой по 6 самых частых в Коране новых слов;
   - затем «Частые слова Корана»: те из 300 самых частых лемм, которых ещё не было.
   
   Одно слово попадает только в один набор, в первый по порядку. Из 102–78 взято по 6 слов, а не по 12, чтобы весь словарь уложился в 350–450 слов.
3. Две леммы QAC объединены, потому что ученик видит в них одно слово: `>agonato` объединено с `>agonaY`` (أَغْنَى), `ka`firuwn` — с `kaAfir` (كَافِر).
4. Пример к слову — самый короткий аят с этим словом из его собственной суры. Для частых слов пример берётся из Джуз Аммы, а если там слова нет — из любой суры. `example.ar` — аят дословно из источника, `example.form` — слово в том виде, в каком оно стоит в аяте (вместе с приставками).
5. Переводы слов (`ru`) и подсказки (`note`) написаны вручную, сверены по смыслу с Кулиевым.
6. Покрытие: слово текста засчитано, если выучены все его основы. Приставки и слитные местоимения считаются известными. Только за счёт них (لَهُ، لَكُمْ) покрыто 2,47 % текста.

Покрытие по числу выученных слов: 50 → 28,8 %; 100 → 36,9 %; 200 → 53,3 %; 300 → 65,9 %; все 417 → 76,0 %.

## Транслитерация

Русскими буквами, долгота гласных не обозначается. Схема описана в `meta.translit_scheme`.

## Что учесть

- В режиме «мусхаф» знаки паузы (ۖ ۗ ۚ) приклеены через пробел к предыдущему слову, а «يَا أَيُّهَا» — одно слово, как в QAC. Поэтому в поле `t` бывает пробел. Если в слове две основы (например, مِمَّا = مِنْ + مَا), в поле `ids` перечислены обе.
- Глаголы, которые в Коране встречаются только в настоящем времени, даны в форме прошедшего, как принято в словарях (например, وَذَرَ — «оставлять»).
