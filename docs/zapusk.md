# Как запустить «Калиму» в Telegram

Серверный код и база данных не нужны. Приложение состоит из статических файлов. Прогресс каждого ученика хранится в его
аккаунте Telegram (CloudStorage), поэтому он виден и с телефона, и с компьютера.

## 1. Выложить папку в интернет (нужен адрес https)
Подойдёт любой хостинг статических файлов, например Vercel (бесплатно). Выкладывать нужно всю папку `kalima`,
кроме `variants/`, `variants.html`, `shots/` и `docs/`. Получится адрес вида `https://kalima-xxxx.vercel.app`.

## 2. Создать бота
1. Откройте в Telegram @BotFather и отправьте команду `/newbot`.
2. Придумайте имя (например, «Калима: слова Корана») и адрес бота, который заканчивается на `bot`.
3. Бот готов. Токен, который пришлёт BotFather, никому не показывайте. Для мини-приложения он не нужен.

## 3. Подключить мини-приложение
- **Кнопка в чате бота:** в @BotFather откройте `/mybots`, выберите бота, затем Bot Settings → Menu Button →
  Configure menu button. Пришлите адрес из шага 1 и подпись кнопки, например «Учить слова».
- **Прямая ссылка (по желанию):** команда `/newapp` в @BotFather. После неё приложение можно открыть ссылкой
  `t.me/<бот>/<название>` и отправить её в канал.
- Описание бота: в `/mybots` → Edit Bot → Edit Description, например «Учите слова Корана по 10 за урок,
  чтобы понимать текст при чтении».

## 4. Проверить
Откройте бота с телефона и нажмите кнопку меню. Пройдите урок, закройте приложение и откройте снова: прогресс
должен сохраниться.

## Бот с приветствием (Cloudflare Worker)
Код бота лежит в папке `bot/`, он уже выложен: https://kalima-bot.medina-vibecode.workers.dev
На «Старт» бот отвечает приветствием и кнопкой «Открыть тренажёр». Кнопка меню и описание бота настраиваются сами.

Подключить один раз:
1. Создайте бота в @BotFather (`/newbot`) и скопируйте токен.
2. В папке `bot` выполните `npx wrangler@4.40.0 secret put BOT_TOKEN` и вставьте токен. Он хранится в Cloudflare
   в зашифрованном виде, в коде и на GitHub его нет.
3. Откройте в браузере https://kalima-bot.medina-vibecode.workers.dev/setup. Должно появиться «Бот настроен.».
4. Напишите боту /start.

## Сколько пользователей (/stats)
Бот записывает каждую, кто нажала «Старт» или открыла приложение: только номер аккаунта Telegram, даты и сколько
выучено. Имён и переписки нет. Автор один раз отправляет боту `/stats КОД` (код хранится секретом `STATS_CODE` в
Cloudflare), дальше достаточно просто `/stats`. Остальным бот цифры не показывает.

## Сообщения автору
Всё, что человек пишет боту (текст, голосовое, фото), приходит автору, то есть тому, кто подключён через `/stats КОД`.
Чтобы ответить, автор нажимает «Ответить» на этом сообщении, и бот отправляет ответ человеку. В базе хранится только
связка номеров сообщения и аккаунта, сам текст не сохраняется.

## Мини-тест в напоминании

В напоминание встроен тест «Слово дня» на кнопках под сообщением (`bot/quiz.js`). Виджет Telegram с 14.11.2026 отклоняется (`INPUT_MEDIA_WIDGET_NOT_ALLOWED`), виджет бот пробует только на аккаунте автора (таблица `admins`), остальным всегда кнопки. Когда у автора снова придёт виджет, можно включить его всем. Слова для него лежат в `bot/quiz-words.js`: после правок в `data/words.json` выполнить `node bot/make-quiz-words.mjs` и задеплоить бота.

## Слово дня по подписке

Предложение приходит один раз после `/start`, подписка хранится в таблице `daily`, отправка каждый день в 9:00 (по Москве или по времени телефона, если включено в приложении). Тем, у кого включено напоминание хифза, отдельно не приходит: слово уже внутри напоминания. За один запуск по расписанию уходит не больше 20 сообщений, остальные уйдут через 5 минут.

Разовая рассылка предложения: в `daily` ставится `pending = 1`, дальше отправляет расписание.
