# Промпт по формуле (шаг 3)

**Эстетика.** «Ночное чтение»: почти чёрный фон с зеленцой (не #000); одно тёплое пятно света над страницей аята, как от лампы;
узкий гротеск Sofia Sans Condensed в заголовках, Commissioner в тексте, Amiri для арабского; один медный акцент только на
изучаемом слове и главной кнопке; списки линиями вместо карточек; много воздуха вокруг арабского текста.

**Референс.** Своих референсов нет. Ощущение: страница мусхафа вечером при лампе, а не игровое приложение.

**Интент.** За три секунды человек понимает: «вот аят, вот это слово значит "Господь", я могу выучить такие слова».

**Рамки.** Всегда: настоящий текст Корана (Tanzil) и перевод Кулиева, огласовки, кнопки от 52px, телефон в первую очередь.
Никогда: золото на чёрном, полумесяцы и мечети как декор, неон, эмодзи вместо иконок, выдуманные цифры,
шрифты без кириллицы для русского текста, длинное тире в кнопках, «три карточки по центру».

**Структура (выбрано: А + мусхаф из Б).** Главная (аят со словом, урок, повтор, текущая сура, все суры) →
урок (карточки новых слов → тест из трёх вариантов на аяте → итог с днями повтора) → оглавление сур → сура по аятам,
знакомые слова подсвечены, касание открывает карточку слова.
