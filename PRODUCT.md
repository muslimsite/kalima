# Продукт

- Дело и для кого: мини-приложение в Telegram-боте, тренажёр слов Корана. Для начинающих: только начали учить арабский,
  читают Коран, но перевод почти не знают. Цель — при чтении понимать, что написано.
- Целевое действие: открыть бота и пройти короткий урок (карточки → тест из трёх вариантов), вернуться к повтору.
- Режимы: карточки (слово → перевод), тест из трёх вариантов, слова по сурам (Аль-Фатиха, затем джуз «Амма»),
  повтор забытых слов через интервалы.
- Тон: спокойный, уважительный, тёплый, без игровой суеты и без клише (полумесяцы, золото, мечети со стока).
- Настоящие материалы: нет. Логотипа, списка слов, озвучки нет — словарь собираем сами из самых частых слов Корана.
- Хранение прогресса: на телефоне (Telegram CloudStorage, запасной вариант localStorage), без сервера.
- Допущения:
  - Рабочее название «Калима» (كَلِمَة — «слово»), можно сменить.
  - Перевод смыслов — по общепринятым русским переводам (Кулиев, Османов), с огласовками и транскрипцией.
  - Озвучки пока нет; можно подключить позже.
  - Без выдуманных цифр: частоту слов показываем только посчитанную по корпусу.
